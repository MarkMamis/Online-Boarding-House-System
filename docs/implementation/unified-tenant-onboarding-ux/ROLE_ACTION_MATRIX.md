# Role Action Matrix: Tenant Onboarding

| Stage / Status | Student Actions | Landlord Actions | Admin Actions | Backend Authorization Policy |
|---|---|---|---|---|
| **Booking Approval** | Receives notification of booking approval; move-in workflow unlocks. | Approves or declines booking in Landlord Bookings. | Can monitor booking records. | `BookingPolicy::approve`, `BookingPolicy::cancel` |
| **Stage 1: `pending`** | Uploads verification files (`documents[]`) to `student.onboarding.upload_documents`. | Views incoming tenant with note "Waiting for student to upload". | Inspects onboarding record. | `TenantOnboardingPolicy::uploadDocuments` (Only assigned student) |
| **Stage 2: `documents_uploaded`** | Reviews rental agreement (`<x-onboarding.contract-document>`), draws e-signature, checks consent, submits to `student.onboarding.sign_contract`. | Reviews uploaded files; can approve (`action=approve`) or request re-upload (`action=reject`). Can also sign as landlord via `landlord.onboarding.sign_contract`. | Views uploaded files and contract preview. | `TenantOnboardingPolicy::signContract` (Student), `TenantOnboardingPolicy::approveDocuments` (Landlord), `TenantOnboardingPolicy::signContractAsLandlord` (Landlord) |
| **Stage 3: `contract_signed`** | Selects payment method (GCash, Bank, Cash), uploads proof and enters reference number, submits to `student.onboarding.pay_deposit`. | If not yet signed as landlord, can apply saved profile signature. Waits for student payment. | Views signed contract and timestamp. | `TenantOnboardingPolicy::payDeposit` (Student), `TenantOnboardingPolicy::signContractAsLandlord` (Landlord) |
| **Stage 4: `deposit_paid`** | Views calm waiting state: "Payment Under Review". Can download PDF contract copy. | Inspects payment details & proof screenshot; clicks `Approve Payment & Finalize Move-in` (`action=approve_payment`) or `Reject Payment` (`action=reject_payment`). | Inspects payment submission record and proof. | `TenantOnboardingPolicy::approveDocuments` (Landlord only) |
| **Stage 5: `completed`** | Views Welcome Banner & Digital Tenant Pass with Digital ID (`TID-XXXXXX`). Can download signed contract PDF or navigate to room details. | Views completed record with active resident status and Digital Tenant ID. | Views completed onboarding in Monitoring Pipeline. | Read-only across all roles once finalized. |
