# Document Status Source Matrix

| Page | Route | Displayed Field | Actual Data Source | Document Version Selection | Verification Rule | Expiration Rule | Accreditation Rule | Mutation Capability | Corrected Behavior |
|---|---|---|---|---|---|---|---|---|---|
| **Landlord Profile — Overview** | `/admin/users/landlords/{id}` | Compliance Summary Badges | `LandlordDocumentStatusService::resolveDocumentStatus()` | Active / Current (`is_current = true`) | `missing`, `pending`, `approved`, `rejected` | N/A (Summary view) | Required docs must both be `approved` for `is_compliant` | Read-only with deep link to Documents tab | Unified with centralized status service |
| **Landlord Profile — Documents & Requirements** | `/admin/users/landlords/{id}?tab=documents` | Document List, Numbers, Expiration, Verification Badges | `LandlordDocumentStatusService` + `DocumentExpirationService` | Current (`is_current = true`) + Historical versions (`is_current = false`) | `Approved`, `Pending`, `Rejected`, `Not submitted` | `Valid`, `Expiring in X days`, `Expired X days ago` | Individual prerequisite status | `Approve` / `Reject` on pending; `View` / `Download` / `Re-approve` on processed | Accurately shows 60-day warning window and separate verification states |
| **Landlord Accreditation** | `/admin/approvals/landlords?tab=permits` | Permit & Safety Badges, Review Controls | `LandlordDocumentStatusService::resolveDocumentStatus()` | Active / Current (`is_current = true`) | Authoritative resolved status (`missing`, `pending`, `approved`, `rejected`) | Computed via service | Landlord accreditation prerequisites checked independently | `Approve` / `Reject` / `Revoke` with confirmation modals | Fixed `property_exists` defect; reflects true status |
| **Document Review Queue** | `/admin/documents/verification` | Verification Queue Table | `LandlordDocument::current()` | Current submissions (`is_current = true` default; `history=1` opt-in) | `pending`, `approved`, `rejected` | Derived dynamically from `expiration_date` | Document-level review item | `Approve`, `Reject` with mandatory reason | Preserves history, atomic sync to profile |
| **Compliance Monitor** | `/admin/documents/monitoring` | Lifecycle Expiration Monitoring | `LandlordDocument::current()` | Current submissions (`is_current = true`) | `pending`, `approved`, `rejected` | `valid` (>60d), `expiring_soon` (<=60d), `expired` (<=today) | Monitor compliance health | Read-only with preview/download | Verified and expiration statuses decoupled |
| **Action Center** | `/admin/action-center` | Pending Document Reviews, Expiring Compliance | `LandlordDocument::current()->where('verification_status', 'pending')` and `expiringSoon()` | Current submissions | `pending` queue count | Approved documents <= 60 days to expiry | High-level operations cockpit | Deep links to queues | Fixed conflicting `->valid()->expiringSoon()` scope chain |
